# tavern-stack

两部分：

- 仓库根目录：Tavern Stack，一个 SillyTavern 扩展（`manifest.json`、`index.js`、`profiles.js`、`style.css`）。
- `stack/`：SillyTavern 加 LLM 网关的 Docker 部署、seed、聊天工具，见 `stack/README.md`。

## Tavern Stack 扩展

只用酒馆官方的扩展接口（`SillyTavern.getContext()`），不依赖酒馆助手。

- 规则（profile）：按角色名决定发什么提示词。一条规则有名称、适用角色（名字里包含的文字，或 `/正则/`）、若干提示词（标签、深度、role、文字）。匹配的角色在每次生成前，这些提示词用 `setExtensionPrompt` 插进聊天里，和预设、世界书无关，换预设也在。默认带一条「大凉龙虎传」：页眉和落卷每轮必须输出（七格页眉的字段取自 v4.15 世界书，第一格、第二格也是 v4.11 的时间脚本读的那两格）。
- 设置页：扩展 → Tavern Stack。可开关扩展和悬浮按钮，新建、删除、编辑规则和提示词。设置存在 ST 的扩展设置里。
- 悬浮按钮 🧰：可拖动，位置会记住；点一下打开面板，再点关闭。面板总在同一个位置（右边、输入栏上方），不跟着按钮跑，所有东西直接摆出来：当前角色匹配的提示词（可勾选）；写（代写候选）；画（此刻、POV、我、NPC、特写、景、输入框；没有生图的部署里没有这一组）；其他（总结、全屏、设置）。它取代了输入框下面的快捷回复栏（seed 里已关掉）。
- 没有斜杠命令：代写、画图、总结的逻辑在 `story.js`，`actions.js` 把它接上页面，按钮直接调用。画图是把完整的 `/sd …` 放进输入框，改完回车才出图；总结在弹窗里显示，复制后贴进作者注释；朗读（Edge TTS）也读 `story.js` 挑出的故事部分。`Alt+/` 等键盘快捷键仍在 `stack/seed/scripts/page.js`，`Alt+/` 调用扩展的「代写候选」。
- 代写候选卡：最新一条角色回复下面（在聊天流里，不是悬浮窗）有一张「代写」小卡。点「生成候选」，按最新剧情写 4 种做法不同的下一步；输入框里已有字时，那些字是草稿，4 条是它的 4 种写法；人称跟着最新剧情对玩家的称呼走（写名字就第三人称），不默认用「我」；点一条候选，放进输入框：输入框空着就直接放，已经有字就接在后面另起一行，不覆盖，也不发送。「填入整段」把 4 条都放进去，「重新生成」换一批。换了 swipe、改了回复、来了新消息，旧候选就作废；玩家自己的消息在最后时不显示。设置页可关。每点一次生成就是一次请求。
- 群聊没有「当前角色」，规则不生效。

## 安装

在 ST 的扩展页 Install extension，填 `https://github.com/aar0u/tavern-stack`；`stack/` 里的部署会自动装它（`stack/init.sh`）。更新在扩展页点更新。

## 检查

```
node --test profiles.test.mjs suggest.test.mjs story.test.mjs
```

测的是规则、代写候选和 `story.js` 的逻辑（不含页面）；`index.js`、`actions.js`、`tail.js` 和页面要在 ST 里看。
